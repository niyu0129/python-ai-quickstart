## 📋 怎么发到手机 · 详细步骤

> **先说结论**：9 个文件一个个发很烦，**先合并成一个文件**再发，30 秒搞定。
> 合并脚本已经写好了，见下面「第 0 步」。

---

### 第 0 步：合并成一个文件（推荐）

**最简单的办法：双击**

在资源管理器里打开**本仓库的根目录**，双击 `merge_mobile.bat`，
跑完就生成好了，什么都不用输。

**或者用命令行**：

```powershell
cd <本仓库根目录>
powershell -ExecutionPolicy Bypass -File .\merge_mobile.ps1
```

> 提示：Windows 自带的 PowerShell 5.1 就是 `powershell`；
> 如果你装了 PowerShell 7（`pwsh`），把它换成 `pwsh` 也行。

跑完会在根目录生成：

```
手机版_全套合集.md          # 约 83 KB / 3600 行
```

**如果提示"无法加载文件，因为在此系统上禁止运行脚本"**，先执行这一行再重试：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

**不想用脚本？** 用这行纯命令也能合并（效果一样，只是没有封面目录）：

```powershell
cd <本仓库根目录>
Get-ChildItem mobile\*.md | Where-Object Name -ne 'README.md' |
  Sort-Object Name |
  ForEach-Object { "`n`n---`n`n# 【$($_.Name)】`n"; Get-Content $_ -Raw -Encoding UTF8 } |
  Set-Content 手机版_全套合集.md -Encoding UTF8
```

### 方式一：微信文件传输助手（最通用，推荐）

**电脑上：**
1. 登录电脑微信
2. 点左侧「文件传输助手」（手机微信里也能看到）
3. 把 `手机版_全套合集.md` **直接拖进聊天窗口**，发送

**手机上：**
1. 打开微信 → 文件传输助手
2. 看到那个 `.md` 文件，**点开**
3. 右上角 `···` → **用其他应用打开**
4. 选择：
   - **WPS Office** → 能看，等宽字体对齐正常（推荐）
   - **备忘录 / 记事本** → 能看能编辑，但代码块可能错位
   - **语雀 / 飞书 / Notion** → 排版最好（见方式三）

> ⚠️ 微信里直接预览 `.md` 是纯文本，格式会丢。**一定要"用其他应用打开"。**

---

### 方式二：复制粘贴进微信收藏（不用装任何 App）

适合只想要其中一两份的情况。

**电脑上：**
1. 用记事本或 VS Code 打开目标文件
2. `Ctrl+A` 全选 → `Ctrl+C` 复制

**手机上：**
1. 手机微信 → 我 → 收藏 → 右上角 `+` 新建笔记
2. 长按空白处 → **粘贴**
3. 右上角 `···` → **在聊天中置顶**（这样打开微信就能看到）
4. 收藏的笔记**支持搜索**，找内容很快

> 💡 缺点：一次只能粘一份，而且代码块的等宽对齐在微信收藏里会丢。
> 所以**优先用方式一**。

---

### 方式三：粘进云笔记（排版最好，跨设备同步）★ 体验最佳

**语雀 / 飞书文档 / Notion 都支持直接粘贴 Markdown：**

1. 手机或电脑上打开网页版，新建一个文档
2. 把文件内容全选复制，粘贴进去
3. **自动渲染成标题、列表、代码块**，手机上排版最舒服
4. 还能随时加自己的笔记、改代码片段
5. 手机 App 打开同一个文档，自动同步

**Obsidian（进阶）：**
- 把整个 `mobile` 文件夹放进你的 Obsidian 库目录
- 手机装 Obsidian App，配合坚果云 / OneDrive 同步
- 好处：离线可看，双链跳转，永久保存

---

### 方式四：导出 PDF（想打印或发给别人时）

手机看 PDF 比 Markdown 舒服，但代码块不能复制。

**推荐用云笔记中转：**
1. 把内容粘进**语雀 / 飞书**
2. 用它们自带的「导出 PDF」功能
3. 导出的 PDF 发到手机

**或用 VS Code：**
1. 装扩展 **Markdown PDF**
2. 打开 `.md` 文件 → `Ctrl+Shift+P` → 输入 `Markdown PDF: Export (pdf)`

---

### 方式五：其他传输工具

| 工具 | 适合 | 备注 |
|---|---|---|
| **QQ** | 传大文件 | 「我的电脑」直接拖文件 |
| **钉钉 / 企业微信** | 公司电脑 | 发给自己的会话 |
| **OneDrive / 坚果云** | 要长期同步 | 手机装 App 自动同步整个文件夹 |
| **邮件** | 要归档 | 附件发给自己，手机收 |
| **数据线** | 完全没网 | 手机连电脑，复制到「下载」文件夹 |

## ⏰ 发到手机之后怎么看（学习法）

手机不适合写代码，但非常适合做这三件事：

**1. 通勤时背概念**（`手机版_背诵卡.md`）
一次 10 张，不用多。**理解概念比背下来更重要**，看到答不上来的就标记，回家补。

**2. 排队时看速查**（`Python速查` / `AI应用速查`）
不要通读，**用搜索**。比如今天卡在"列表推导式"，就搜"推导式"看那一节。

**3. 睡前复盘**（`每日打卡`）
勾今天完成的事，写一行"今天最卡的地方"，第二天先解决它。

**❌ 不要做的事**：
- 不要在手机上看长代码教程（`code/*.py` 那种要在大屏幕上跑）
- 不要只在手机上看不动手 —— **看十遍不如敲一遍**

## 🎯 一句话原则

> **手机用来"记"和"想"，电脑用来"写"和"跑"。**
> 每天电脑上至少敲 30 分钟代码，其余时间用手机巩固。
