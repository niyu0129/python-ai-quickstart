## 🗓 第 1 天 · 装环境

**🎯 目标**
30 秒内新建一个项目并跑出结果

**✅ 今天做什么**
1. 装 uv（一行命令，最快）
2. 装 VS Code + Python 扩展
3. 建项目 + 虚拟环境
4. 跑出第一行输出

**⌨️ 关键命令（复制用）**

装 uv：
```
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

建项目：
```
uv init my-first-ai
cd my-first-ai
uv venv
```

跑脚本：
```
python hello.py
```

**💡 记住**
- 安装 Python 时**必须勾选 Add to PATH**
- 每次写代码前先激活虚拟环境
- 命令行前面出现 `(.venv)` 才算对

**✔️ 完成标准**
能独立建项目、建环境、跑脚本

**📌 产出**：`hello.py`

**🎯 目标**
代码从"能跑"到"能维护"

**✅ 今天学**

- 列表推导式 / 字典推导式

- try / except + **重试**
- 文件读写（pathlib）
- JSON 读写

**💡 三个必背坑**

坑 1：默认参数不能用 `[]`
```python
def bad(x, box=[]): ...   # ❌ 会累积脏数据
def good(x, box=None):    # ✅
    if box is None: box = []
```

坑 2：读文件必须写编码
```python
open(f, encoding="utf-8")   # 不写会中文乱码
```

坑 3：JSON 中文乱码
```python
json.dumps(d, ensure_ascii=False)
```

## 🗓 第 4 天 · 数据三件套

**🎯 目标**
会处理数据、会画图

**✅ 今天学**
- numpy：数组、向量化、矩阵乘法 `@`
- pandas：DataFrame、筛选、groupby
- matplotlib：折线/柱状/散点

**💡 三个关键点**

1. `A * B` 是逐元素乘
   `A @ B` 才是矩阵乘法
   （神经网络里只用 `@`）

2. `axis=0` 是"往下压扁"
   得到的是**每列**的结果

3. **余弦相似度**——今天的重点
   ```python
   a @ b / (np.linalg.norm(a) * np.linalg.norm(b))
   ```
   向量检索全靠它，范围 -1 到 1

**✔️ 完成标准**
能读一份 CSV、算出分组统计、画一张图

**📌 产出**：`cost_report.py`

## 🗓 第 5 天 · 机器学习 30 分钟

**🎯 目标**
看懂"训练模型"的完整流程

**✅ 今天学**
- 特征 X、标签 y、模型 f
- sklearn 六步：准备→划分→预处理→训练→预测→评估

**💡 三条铁律**

1. **测试集绝不能用 `fit_transform`**
   只能用 `transform`
   （要模拟"没见过的新数据"）

2. 训练集 99% + 测试集 65% = **过拟合**
   解决：简化模型 / 加数据 / 正则化

3. PyTorch 训练循环五步
   ```
   前向 → 损失 → zero_grad
        → backward → step
   ```
   `zero_grad` 忘了写，梯度会累加，训练直接崩

**✔️ 完成标准**
能解释"为什么模型会过拟合"

**📌 产出**：`ml_basics.py`

## 🗓 第 6 天 · 调用大模型 API ★

**🎯 目标**
把大模型接进自己的程序

**💡 核心认知**
**大模型就是一个 HTTP 接口**
你发一段文字，它回一段文字

**✅ 今天学**
1. 配 `.env`（密钥绝不写死在代码里）
2. 用 `requests` 手写一次调用（理解原理）
3. 用 `openai` SDK 调用
4. **流式输出**（打字机效果）
5. **让模型返回 JSON**（工程化关键）

**💡 参数怎么调**
- 抽取/分类/代码 → `temperature=0`
- 创意写作 → `temperature=0.8`
- `max_tokens` **必须设上限**，不然烧钱

**💡 三个必背细节**
- 密钥：`.env` + `.gitignore`
- 流式的 usage 在**最后一帧**
- 模型输出的 JSON 进数据库前**必须校验**

**✔️ 完成标准**
能自己封装一个带重试和日志的 `LLM` 类

**📌 产出**：`llm.py`

## 🗓 第 8 天 · 向量检索 ★

**🎯 目标**
让程序"看懂"语义

**💡 一句话原理**
把文字变成一串数字（向量）
语义相近的文字，向量方向也相近

**✅ 今天学**
- 什么是 embedding
- 余弦相似度（范围 -1 到 1）
- 归一化后，点积 = 余弦相似度
- 手写一个 40 行的向量库

**💡 为什么不能只用关键词**
用户问"网络连不上了"
文档写的是"路由器密码怎么重置"
字面完全不同，但意思相关 —— 只有向量能匹配上

**💡 五个坑**
1. 不同模型的向量**不能混用**
2. 换 embedding 模型必须**重建整个库**
3. 必须先归一化
4. 文档要切块，不能整篇塞进去
5. 向量库要支持元数据过滤

**✔️ 完成标准**
输入口语化问题，能检索到正确文档

**📌 产出**：`semantic_search.py`

## 🗓 第 9 天 · 项目二：RAG ★★

**🎯 目标**
让 AI 读懂你自己的文档

**💡 一句话**
先从你的文档里查出相关内容
再把内容塞进提示词让模型回答

**✅ 两条流水线**

离线（只做一次）：
```
读文档 → 切块 → 算向量 → 存库
```

在线（每次提问）：
```
问题向量化 → 检索 top-k
→ 组装提示词 → 生成答案
```

**💡 切块是效果的关键**
- 中文 300–800 字符
- 重叠 10%–20%（防止句子被切断）
- 太大：混入无关信息
- 太小：语义不完整

**💡 提示词必须写死这三条**
1. 只依据资料回答
2. 资料没有就说"无法回答"
3. 末尾标注来源

**💡 效果不好先查这里（按顺序）**
1. 切块太大 → 调小
2. 没归一化
3. embedding 模型不适合中文
4. 索引没重建
5. 加查询改写
6. 加混合检索 / rerank
7. **最后才考虑换生成模型**

**✔️ 完成标准**
问文档里没有的问题，模型敢说"不知道"

**📌 产出**：`rag.py`

## 🗓 第 10 天 · Agent 工具调用

**🎯 目标**
让 AI 会"做"事，不只是"说"

**💡 核心认知**
**模型不会真的执行你的函数**
它只返回"我要调用 xxx，参数是 xxx"
真正的执行永远在你的代码里

**✅ Agent 三要素**
大模型 + 工具 + 循环

**💡 四个最容易写错的地方**

1. 必须把模型的 `tool_calls` 消息
   也 append 进 messages

2. `tool_call_id` 必须一一对应

3. **必须有 `max_steps` 上限**
   没有上限的 Agent 是定时炸弹

4. `json.loads(参数)` 要包 try

**💡 让工具调用更准的第一杠杆**
把 `description` 写清楚：
**什么时候用**、参数格式、返回什么

**💡 安全红线**
模型给你的内容，永远当**不可信输入**

**✔️ 完成标准**
能算数、能读文件的聊天机器人

**📌 产出**：`agent_min.py`
