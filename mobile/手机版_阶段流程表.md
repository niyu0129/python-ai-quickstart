# 🗂 阶段流程表（手机版）

> 横向看是阶段，纵向看是每一步的"进入条件 → 动作 → 产出 → 通过标准"。
> 手机上每张表只有 3 列，不会挤。

---

## 阶段 0 · 准备（第 1 天）

```
│ 环节    │ 动作            │ 通过标准
─────────┼────────────────┼─────────────────
│ 装引擎  │ 装 uv 或 Python │ python --version 有输出
│ 装编辑器│ VS Code + 扩展  │ 能打开 .py 且高亮
│ 建隔离  │ 虚拟环境        │ 命令行出现 (.venv)
│ 跑测试  │ hello.py        │ 看到输出
│ 管密钥  │ .env + gitignore│ git status 里没有 .env
│ 装库    │ requests        │ import 不报错
```

**进入下一阶段的条件**
能在 30 秒内新建项目并跑出脚本

## 阶段 1 · 语言基础（第 2-3 天）

```
│ 环节      │ 动作               │ 通过标准
───────────┼───────────────────┼──────────────────
│ 变量类型  │ 5 种类型 + 转换     │ 知道 int("5")
│ 字符串    │ f-string 练 5 个    │ 能拼出提示词
│ 列表      │ 增删改查 + 切片     │ 会 append 消息
│ 字典      │ get + 嵌套          │ 会读 payload[a][0]
│ 判断循环  │ if/for/while       │ 会写逐块打印
│ 函数      │ 默认参数 + kwargs   │ 知道默认值不能用 []
│ 推导式    │ 列表/字典推导       │ 能清洗字符串列表
│ 异常      │ try + 重试          │ 会写指数退避
│ 文件      │ pathlib + JSON      │ 中文不乱码
│ 类        │ 写 ChatSession      │ 会 self.xxx
│ 模块      │ import + .env       │ 会用 os.getenv
```

**进入下一阶段的条件**
能写出带异常处理、带重试、能读写文件的函数

## 阶段 2 · 数据与模型（第 4-5 天）

```
│ 环节       │ 动作              │ 通过标准
────────────┼──────────────────┼──────────────────
│ numpy 基础 │ 创建 + 索引        │ 知道 shape/axis
│ 向量化     │ 布尔索引 + 广播     │ 会用 mask 筛选
│ 矩阵运算   │ @ 乘法             │ 分清 * 和 @

│ 画图       │ 折线+柱状+散点      │ 中文不乱码
│ sklearn    │ 六步流程           │ 知道 fit/transform 区别
│ 过拟合     │ 做对比实验          │ 能解释原因
│ PyTorch    │ 训练循环           │ 五步说得出
```

**进入下一阶段的条件**
能解释"为什么测试集不能用 fit_transform"

## 阶段 3 · 接入大模型（第 6-7 天）★

```
│ 环节       │ 动作               │ 通过标准
────────────┼───────────────────┼──────────────────
│ 理解原理   │ 手写 requests 调用  │ 看懂返回 JSON
│ 用 SDK     │ 官方库调用          │ 换厂商只改 .env
│ 人设       │ system 消息         │ 输出符合要求
│ 调参       │ temperature/max    │ 知道抽取用 0
│ 流式       │ stream=True        │ 打字机效果 + usage
│ 结构化输出 │ 强制 JSON          │ 能稳定解析
│ 校验       │ Pydantic           │ 格式错不崩
│ 封装       │ LLM 类             │ 超时+重试+日志
│ 记忆       │ messages 列表       │ 连聊 5 轮记得
│ 裁剪       │ 保留最近 N 轮       │ 不会超上下文
│ 成本       │ token 统计          │ /stats 能看花费
```

**进入下一阶段的条件**
有一个能连续对话、能看花费、崩了不挂的聊天机器人

## 阶段 4 · 知识与检索（第 8-9 天）★★

```
│ 环节       │ 动作               │ 通过标准
────────────┼───────────────────┼──────────────────
│ embedding  │ 算真实向量          │ 知道维度和来源
│ 相似度     │ 归一化 + 点积       │ 分数合理（>0.7 相关）
│ 向量库     │ 手写 VectorStore    │ 能存能查能持久化
│ 语义搜索   │ 口语问题检索        │ 命中正确文档
│ 读文档     │ txt/md/pdf         │ 编码正确
│ 切块       │ size+overlap       │ 块大小均匀
│ 建索引     │ 批量化入库          │ 条数对得上
│ 检索生成   │ 拼提示词 + 约束     │ 答案有依据
│ 来源标注   │ 附 [来源: 文件名]   │ 能追溯到原文
│ 拒答       │ 问不存在的问题      │ 敢说"无法回答"
│ 优化       │ 查询改写/混合检索   │ 命中率有提升
```

**进入下一阶段的条件**
问文档里没有的问题，模型不编造

## 阶段 5 · 工具与自动（第 10 天）★

```
│ 环节       │ 动作               │ 通过标准
────────────┼───────────────────┼──────────────────

│ 熔断       │ 预算上限            │ 超了就中断
│ 接机器人   │ 聊天机器人会算数    │ 能读项目文件
```

## 卡的判断（每个阶段都适用）

```
这个阶段的"通过标准"做到了吗？
      │
      ├─ 做到了 ──▶ 进下一阶段
      │
      └─ 没做到
            │
            ▼
      卡在同一个点超过 30 分钟？
            │
            ├─ 是 ──▶ 查急救手册 → 问 AI
            │         → 写 10 行最小复现
            │         → 还不行就先跳过
            │            标记下来，往下走
            │
            └─ 否 ──▶ 继续琢磨
```

> **不要为了一个卡点停三天。**
> 很多时候学到后面，前面的问题自己就通了。
